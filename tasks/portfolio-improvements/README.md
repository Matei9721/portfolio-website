# Portfolio Improvement Tasks

Each file in this directory is designed to be loaded and completed in a separate work session.

## Usage

Start a future session with a request such as:

> Implement S03 from `tasks/portfolio-improvements/03-vite-migration.md`.

Complete prerequisite tasks first unless the selected file says otherwise. Tasks marked **USER INPUT** should not proceed past that decision gate without Matei's response.

## Shared definition of done

- Requested scope is implemented without unrelated changes.
- Relevant tests pass.
- `npm run build` succeeds without suppressing CI warnings.
- Visible changes are checked on desktop and at 390 x 844.
- Interactive changes are checked with keyboard navigation and accessible names.
- Documentation is updated when commands or architecture change.
- The working tree is reviewed before handoff.

## Recommended order

1. Foundation: S01-S05
2. Architecture and experience: S06-S11
3. Content and public proof: S12-S15
4. Optimization and release: S16-S19
